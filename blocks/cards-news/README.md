# cards-news

Custom **cards** block. Purpose: News/event cards with photo, date tag, H3 title, excerpt and Read More button; 3 across on desktop.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: cell 1 image; cell 2 date paragraph (before the heading), H3 title, excerpt, trailing Read More link paragraph.
