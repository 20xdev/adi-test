# form

Custom **form** block. Purpose: Simple sign-up form such as the "Stay in touch" newsletter form.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per field: Label | Type (text, email, tel, number, date, textarea, select, checkbox, submit) | Placeholder or options (select: comma- or line-separated) | Required (yes); config rows with Type "action" (submission URL in cell 3) and "success" (message in cell 1). Alternatively a single link to a spreadsheet JSON with columns Label, Name, Type, Placeholder, Options, Mandatory.

## Supported variations

No variations.
